# Botanic Sklad — simple remaster

Jednodušší UI podle přiložené šablony.

## Změny
- jednoduchý monochromatický layout bez sidebaru a velkých glass panelů
- hlavní tabulka skladu jako primární pracovní plocha
- kompaktní toolbar: hledání, filtry, řazení, zobrazení, import/export
- rychlé akce přes `•••`: detail, přesun, výdej
- expirace používá pouze `MM/YY`
- boxy jsou číselné bez `B-` a bez doplňování nul
- jedna pozice může obsahovat více boxů/pytlů
- hmotnosti jsou vždy v gramech
- zachována lokální data přes localStorage
- přidána kompatibilní vrstva `simple-ui.js`, původní `app.js` zůstává v repu
